# Boundary-case blind review packet v1

**Purpose:** independently check whether the project's operational rules are applied consistently across similar and contrasting cases.

**For the reviewer:** Please review each case independently against all applicable rules. Do not assume a case tests only one rule. Do not search for prior labels, model outputs, or earlier review packets. Use only the case details below and the linked public CHANEL guideline. These are proposed scripts with supplied metadata, not verified published videos. The project rule IDs are local identifiers, not official CHANEL rule numbers.

**Source:** CHANEL, [Social Media Guidelines](https://www.chanel.com/us/makeup/social-media-guidelines/), especially sections 1–4. Apply the actual-use requirement to product opinions, and assess whether competitor criticism implies impartiality. Do not infer creator intent, actual product use, or finished-video visibility beyond the facts supplied.

## Reviewer response

For each case, please provide:

1. Verdict: `PASS`, `FLAG`, or `HUMAN_REVIEW`.
2. Relevant project rule ID(s), or “none.”
3. Exact evidence phrase(s) and a short rationale for each applicable rule.
4. Confidence: `high`, `medium`, or `low`.
5. What fact or context, if any, would change your verdict.

Please also provide the review date and a short description of relevant content-policy, advertising, brand-review, or moderation experience. If you prefer not to share background details, write “not provided.”

Do not assume that a missing fact proves a violation. In particular, distinguish “unknown use” from “not used,” and distinguish a personal negative opinion from an explicit or implied claim of impartiality. If different rules produce different case-level outcomes, report each separately and then state the overall verdict.
