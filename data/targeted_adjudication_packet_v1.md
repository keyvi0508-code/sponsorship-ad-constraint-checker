# Targeted policy-calibration packet

Please independently review these three fictional sponsored-video scripts. They are a small, targeted calibration set, not a representative sample of creator content. The original dataset labels, previous reviewer decisions, and AI outputs are intentionally omitted.

## Apply these source-grounded project rules

The IDs below are project labels, not official CHANEL rule IDs. See CHANEL's public [Social Media Guidelines](https://www.chanel.com/us/makeup/social-media-guidelines/).

- **CH-CONTEXT-01 — competitor criticism and impartiality:** A creator connected to CHANEL should not represent or imply that criticism of a CHANEL competitor is impartial. Personal criticism alone is not automatically a breach. Use `HUMAN_REVIEW` if it is genuinely unclear whether wording implies a neutral or evidence-based comparison.
- **CH-CLAIM-01 — opinions and actual product use:** Product opinions should reflect actual experience; the reviewer should be a real user of the product. If the script concerns an identifiable product but the supplied information does not establish whether it was used, consider `HUMAN_REVIEW`. Do not treat `unknown` use as proof either that the creator used it or did not use it. Factual claims need support; no external substantiation is supplied here.
- **Disclosure:** Each script includes a caption disclosure and a spoken CHANEL sponsorship disclosure. Proposed text does not establish finished-video visibility or audibility.

## Verdicts

- `PASS`: no in-scope issue is apparent from the supplied text and metadata.
- `FLAG`: the supplied information clearly conflicts with a rule.
- `HUMAN_REVIEW`: a meaningful question, such as impartiality implication or actual product use, cannot be resolved from the supplied information.
